# Coleta de Material

## O que pedir ao usuário

```
Para rodar a análise, me manda:

1. O material da sabatina (um ou mais):
   • transcrição (colada aqui ou como arquivo) — melhor opção
   • link de matéria/cobertura com as falas citadas
   • link do vídeo + legendas/transcrição automática baixada
   • documento oficial, programa de governo, release da campanha
2. Qual candidato analisar — ou quais, se for comparativo.
3. Contexto: data, veículo, entrevistador, formato.
4. Opcional: qual público ele estava tentando atingir ali (muda o veredito de alguns momentos).
```

## Hierarquia de qualidade do material

| Material | Qualidade | O que permite avaliar |
|---|---|---|
| Transcrição integral com timestamps | **Ótima** | Todos os cinco pilares, inclusive tempo e clipes |
| Transcrição integral sem timestamps | Boa | Todos os pilares; tempo por proporção de texto (estimativa) |
| Transcrição parcial / trechos | Média | Pilares 1 a 4 nos trechos; Pilar 5 não avaliável |
| Matéria de terceiros com citações | Baixa | Pilar 1 e parte do 2; o resto é inferência — declarar |
| Vídeo sem transcrição | **Insuficiente** | Nada. Pedir transcrição. |
| Só o programa de governo | Insuficiente para desempenho | Serve de referência para medir omissões |

## Limitação técnica a declarar na hora de pedir

Vídeo e áudio **não são analisáveis diretamente**. Links de YouTube, Globoplay, podcasts e afins precisam
vir acompanhados de transcrição. Caminhos práticos para o usuário:

- legenda automática do YouTube (transcrição → copiar e colar);
- transcrição publicada pelo próprio veículo;
- matéria de cobertura que reproduza as falas;
- arquivo `.txt`/`.srt`/`.vtt`/`.pdf` colocado no diretório de trabalho da sessão.

Elementos que **nenhuma transcrição captura** e que devem ser declarados como não avaliados:
tom de voz, hesitação, linguagem corporal, suor, olhar, tempo de silêncio antes de responder.
Quando houver descrição desses elementos em matéria confiável, use-a e **atribua a fonte**.

## Material complementar útil (pedir se o usuário tiver)

- Programa de governo registrado — base objetiva para medir **omissões** (Seção 7 do relatório).
- Falas anteriores do candidato sobre o mesmo tema — base para medir **contradição** (Pilar 1, subitem 1.2).
- Sabatina do adversário no mesmo formato — base para o **comparativo** (Seção 15).
- Pesquisas recentes — base para calibrar qual público estava em jogo.
- Análise anterior gerada por esta skill — base para o **modo série**.

## Antes de pontuar, confirme

- [ ] O material foi lido nesta sessão (não é memória nem suposição).
- [ ] Sei quem fala em cada trecho (em debates, atribuição errada invalida a análise).
- [ ] Sei se a transcrição é integral ou cortada.
- [ ] Registrei as limitações na Ficha técnica.
- [ ] Defini a confiança da nota.
